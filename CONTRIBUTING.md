# Contributing to Tiny MD Editor

Thank you for considering a contribution.

## Before opening a pull request

1. Open an issue first for significant features or user-interface changes.
2. Keep changes focused and explain the user-facing outcome.
3. Build the project locally with `dotnet build .\v.3\MarkdownLigero.csproj -c Release`.
4. Do not commit generated `bin`, `obj`, `publish`, portable-package, or ZIP files.

## Pull requests

- Write commit messages and pull-request descriptions in English.
- Include test steps and the Windows version used.
- Preserve the Markdown-only file model unless the proposal explicitly changes it.
- By submitting a contribution, you agree that it may be distributed under GPL-3.0.

## AI-assisted contributions

AI assistance is welcome. Contributors must review generated code, verify that it is safe and functional, and disclose material AI assistance in the pull-request description.
